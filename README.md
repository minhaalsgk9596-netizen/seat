# 자동 좌석배치 (원곡고Ver) — 코드 배포용

선생님들께 보낸 배포용 HTML 파일이 열릴 때 **여기서 최신 코드를 받아갑니다.**

| 파일 | 역할 |
|---|---|
| `app.html` | 앱 코드 전체 (학생 데이터 없음) |
| `version.json` | 최신 버전 번호 |

## 중요

**이 저장소에는 학생 개인정보가 절대 올라가지 않습니다.**
`app.html`의 데이터 자리는 항상 비어 있습니다 (`var EMBEDDED_DATA=null;`).
학생 명단·시험 시간표는 업무포털로 전달하는 배포용 파일 안에만 존재합니다.

배포 스크립트(`deploy.py`)가 push 전에 이 조건을 검사하고, 어긋나면 배포를 중단합니다.

## 업데이트 방법

상위 폴더의 `배포하기.bat` 더블클릭.
